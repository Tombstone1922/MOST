Сайты `.ru` можно открывать напрямую, оставляя VPN-мост включённым.

- Включите «Все сайты .ru без VPN» в разделе «Правила → Сайты без VPN», сохраните изменения и переподключитесь.
- DNS для сайтов без VPN тоже идёт напрямую. Остальные сайты, включая список «Всегда через VPN», продолжают идти через VPN.
