MOST Windows 0.2.0 — предварительная версия для Windows 10/11 x64

НАЧАЛО РАБОТЫ
1. Запустите MOST-Windows-0.2.0-Setup.exe и установите MOST.
   Для переносного варианта распакуйте Portable.zip целиком, затем откройте MOST.exe.
   Папка core должна находиться рядом с MOST.exe. .NET, Python и Java отдельно
   устанавливать не нужно: среда выполнения включена в комплект.
2. Подтвердите разрешение администратора Windows. Оно нужно для VPN-интерфейса TUN.
3. Нажмите «Добавить», вставьте свою HTTP/HTTPS-подписку либо VLESS-ссылки.
   Для обычного HTTP отметьте разрешение в этом же окне. HTTPS-сертификат проверяется.
4. Выберите профиль во вкладке «Серверы». С галочкой «Прямые подключения» видны
   только прямые подключения; без неё — мосты. Неизвестные страны доступны
   в фильтре «Все страны» соответствующего типа.
5. Нажмите «Подключить». MOST проверяет доступ через выбранный профиль.
   На главной показывается фактический IP и страна. Название профиля — только
   подсказка о предполагаемой стране; при несовпадении выводится сообщение.
6. «Отключить» останавливает ядро. Закрытие приложения отключает VPN;
   «Свернуть в трей» оставляет его работающим. Открыть окно можно двойным
   нажатием на значок в области уведомлений.

ПОДДЕРЖИВАЕТСЯ
— VLESS TCP, gRPC, XHTTP; REALITY и TLS.
— Списки VLESS, Base64-подписки, Xray JSON со списком VLESS outbounds.
— Стабильный HWID именно этой Windows-установки, заголовки x-hwid и x-device-os.
  Windows считается отдельным устройством от Android. При лимите устройств
  разрешите его в панели; приложение выводит понятное сообщение об отказе.
— Обновление, переименование и удаление подписок. При неуспешной загрузке
  предыдущие профили сохраняются. Локальные ссылки хранятся отдельно.
— Реальный TUN для Windows через Xray и официальный Wintun.
— Выбор отдельных .exe, работающих напрямую. После изменения исключений
  переподключитесь. Несколько процессов одной программы добавляются отдельно.
— Альтернативный режим локального HTTP/SOCKS-прокси для ручной настройки.
  При выключенном TUN Windows целиком не переключается на VPN.
— Защита сохраняемых настроек/подписок Windows DPAPI для текущего пользователя.
  HWID и подписки сохраняются при переустановке новой версии поверх старой.
— Журнал с удалением VLESS/HTTP URL и UUID перед показом/копированием.

ОГРАНИЧЕНИЯ
Это отдельный клиент для Windows, не запуск Android APK в эмуляторе.
Xray 26.10.21 и Wintun 0.14.1 включены в комплект; загрузки проверяются по SHA-256.
Настройки Android не переносятся автоматически: импортируйте свою подписку один раз.
Публичные/приватные ключи VPN и UUID приложение не создаёт и маршрутизацию
серверной панели не меняет. Если мост выходит через RU вместо DE/NL, проверьте
серверные правила — клиент показывает измеренный выход и предупреждение.
Произвольные routing/script/log из импортированного JSON не исполняются:
импортируются только поддерживаемые VLESS endpoint/transport-поля.
VMess, Shadowsocks, WireGuard и Hysteria в этом первом выпуске не импортируются.
Автоподбор на главной работает в одной подписке, стране и типе подключения.
При сбое пробует другие профили, максимум 12. Рабочий вариант запоминается.
Для автоматического режима нужна подтверждённая страна выхода. Если её не
удалось определить, можно выбрать сервер вручную. Это не режим kill switch.
Закрытый тестовый канал отложен.
Контроль интернета выполняется через loopback HTTP-прокси Xray; прямого
резервного запроса для определения IP нет. При сбое геосервиса IP не выдумывается.

ЗАВЕРШЕНИЕ И ДАННЫЕ
Обычное отключение посылает Ctrl+C в отдельную скрытую консоль Xray, давая ядру
убрать маршруты/DNS/фильтры. При зависании применяется завершение принадлежащего
приложению процесса. Windows Job Object завершает ядро при аварии интерфейса.
Не запускайте несколько VPN одновременно при первой проверке MOST.
Состояние: %LOCALAPPDATA%\MOST\Windows\state.bin — DPAPI, не обычный JSON.
Временная конфигурация ядра существует открытой только в runtime-папке этого
пользователя во время работы и удаляется при отключении/следующем запуске.
Не передавайте папку данных другим людям. Удаление программы не стирает подписки.

ПРОВЕРКИ
В CI выполняются сборка .exe, короткие проверки импорта/маршрутов/DPAPI и
проверка синтаксиса конфигураций TCP/gRPC/XHTTP настоящим Xray без подключения.
Not run: реальное VPN-подключение на Windows 10 и Windows 11, TUN-маршруты,
DNS/IPv6, исключения процессов, смена сети, остановка/авария/выход из Windows,
UI/доступность/масштабирование, установка и удаление на пользовательском ПК.
Реальные подписки на CI не запрашиваются.
У MOST.exe и установщика пока нет коммерческой цифровой подписи Windows.

ОБНОВЛЕНИЯ
Откройте «Обновления»: здесь можно проверить версию, прочитать, что нового,
скачать установщик и запустить его. Перед установкой MOST отключает VPN
и закрывается. Подписки и HWID хранятся отдельно от программы. Установка
открывает обычный мастер Windows и не выполняется без вашего нажатия.
Проверяем версию при запуске и примерно раз в 6 часов, пока приложение
работает, включая трей. Файл берётся только из релизов проекта MOST на GitHub;
проверяются размер и SHA-256. Цифровой подписи Windows у EXE пока нет.
Для перехода с 0.1.0 установите 0.2.0 вручную один раз. В переносной версии
можно использовать установщик или заменить распакованную папку вручную.

В 0.2.0 добавлены избранные серверы и поиск запущенных приложений для
исключений. Во вкладке «Приложения» галочкой отметьте программы без VPN,
сохраните исключения и переподключитесь. Не запущенную программу можно
добавить кнопкой «Выбрать .exe».

Not run: автоподбор и восстановление реального VPN, уведомления Windows,
загрузка/передача установщику обновления на пользовательском ПК, обновлённый
интерфейс на разных DPI и управление с клавиатуры.
