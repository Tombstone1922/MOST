# MOST 0.4.0

- IP и страна фактического выхода: диагностический HTTP-вход Xray принудительно направлен на выбранный outbound proxy. Прямой запрос из UID приложения не используется.
- Проверка доступности через Cloudflare trace и независимый HTTPS 204. Отказ одного сервиса определения IP не считается потерей VPN.
- Автовосстановление: после двух неуспешных циклов горячее переподключение, затем выбранный запасной сервер, с ограничением частоты попыток. Ручная остановка отменяет наблюдение.
- Список приложений доступен в режиме «Все». Первое отмеченное приложение включает исключения «Без VPN». Предыдущий режим «Только» сохранён для совместимости.
- OTA: GitHub Releases, уведомление на главной, ручная проверка, загрузка с прогрессом, проверка размера, SHA-256, имени пакета, кода версии и сертификата, штатное окно установки Android. Источник по умолчанию Tombstone1922/MOST. Требуется однократная публикация через комплект Publish.cmd.
- HWID и HTTP-согласие сохранены.

Обновление: установить APK поверх 0.2.0 / 0.3.0 / 0.3.1. Подпись постоянная MOST.

Контрольная проверка выхода недоступна для пользовательских сложных конфигураций без outbound с тегом proxy; приложение сообщает об этом. При недоступной геодиагностике IP не выдумывается.

Сборка: :app:assemblePlaystoreDebug. Эмулятор, физические устройства и полная тестовая серия не запускались по просьбе пользователя. Сценарии восстановления и установка OTA требуют проверки на устройстве.


# MOST 0.4.2

Страны и автоматический подбор подключения в пределах выбранной подписки, запоминание рабочего профиля, проверка фактического выхода, ручной режим со всеми профилями. Новые статусы помогают отличить отсутствие сети, недоступность подключения, другую страну выхода и исчерпание вариантов. Отказы сервера подписки сохраняются на экране подписок.

Реальное переключение и установка обновления требуют проверки на устройстве; эмулятор по просьбе пользователя не запускается.

# MOST 0.4.3

Мостовые и прямые подключения разделены чекбоксом в выборе страны. По умолчанию показываются мосты; с галочкой — только прямые. После переключения выбери страну. Фильтр не меняет уже работающий VPN сам по себе. Автопереключение остаётся в пределах выбранного типа, страны и подписки. Тип маршрута виден на главной.

После установки и первого открытия включаются фоновые проверки обновлений примерно раз в 6 часов при наличии сети. Разреши уведомления в Android и оставь автоматическую проверку включённой. Android может откладывать проверки; это периодические уведомления, а не мгновенная серверная рассылка. Нажатие открывает обновления MOST. Установка требует обычного подтверждения Android.
