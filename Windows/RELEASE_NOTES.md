Первый предварительный MOST для Windows 10/11 x64.

- Установщик EXE и переносной ZIP, .NET включён: отдельная установка среды не нужна.
- VLESS TCP, gRPC, XHTTP, REALITY/TLS; импорт HTTP/HTTPS, Base64 и Xray JSON, HWID Windows.
- Полный VPN через TUN/Wintun, выбор .exe для работы напрямую, остановка и значок в трее.
- Подписки, раздельный список мостов/прямых, измеренный IP/страна, предупреждение о другой стране выхода.
- Локальные настройки защищаются Windows DPAPI; чужая маршрутизация и скрипты из подписки не исполняются.

Запустите Setup.exe либо распакуйте Portable.zip целиком и откройте MOST.exe. Для TUN требуется разрешение администратора.

Предварительный выпуск. Сборка и короткие проверки выполняются в Actions. Реальное подключение, работа TUN/исключений/IPv6, UI и установка на пользовательских Windows 10/11 не проверялись. Коммерческой подписи Windows у программы и установщика пока нет.

Windows-релиз публикуется отдельно и не меняет Android OTA. Автоматический OTA и закрытый тестовый канал Windows в первый выпуск не входят.
