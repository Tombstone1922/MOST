# MOST release notes

Release notes are shown to users in the application and on GitHub.

- Describe what the user can now do or what became easier, in short everyday language.
- List only shipped changes. Keep internal test results, implementation details, file names, developer instructions and unrun-check reports in the source README or PR description.
- For a small visual-only change, use «Небольшие улучшения интерфейса.»
- Do not claim optimization, speed, reliability or bug fixes unless the release actually changes them.
- Windows: `Windows/RELEASE_NOTES.md`. Android: `ci/release-notes-<version>.md`.
